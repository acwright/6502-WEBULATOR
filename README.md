# 6502 WEBULATOR

Web based emulator app for the [A.C. Wright 6502 project](https://github.com/acwright/6502).

## Prerequisites

- [Node.js](https://nodejs.org/) v20.19+ or v22.12+

## Install

```sh
npm install
```

## Development

```sh
npm run dev
```

Opens a local dev server with hot-reload (default `http://localhost:5173`).

## Build

```sh
npm run build
```

Production output is written to `dist/`. Preview the build locally with:

```sh
npm run preview
```

## Type Check

```sh
npm run type-check
```
